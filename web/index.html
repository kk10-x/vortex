A running system, seen from the inside.

Every particle on this page is a real HTTP request passing through a gateway and three worker processes on this machine. Scroll to change how they are routed, then break something.

Balance

Round robin deals each request to the next worker in turn. Each of the three clusters lights in rotation and serves roughly a third of the load.

Shard

Now the gateway hashes each key onto a ring with 64 virtual nodes per worker. The same key always lands on the same worker, so that worker can keep the key's data warm.

Routing strategy is now consistent hash.

Fail

Each button sends SIGKILL to a real process. For up to about 400 ms the gateway still believes that worker is healthy, so some requests hit a dead port, fail, and are retried on another worker. Then the health check notices.

With consistent hashing, only the dead worker's keys move. Every other key keeps its owner.

Limit

A token bucket admits requests at a steady rate and tolerates a short burst. Anything past that is rejected at the gateway, before any worker is involved.
